## 安装

1. 下载 `Mahjong Copilot_<版本>_aarch64.dmg`（Apple 芯片的 Mac，macOS 14 及以上），打开后把 Mahjong Copilot 拖进「应用程序」。
2. **第一次打开（只需一次）**：app 用我们自己的证书签名，没有经过 Apple 公证，macOS 会拦一次。
   1. 在「应用程序」里双击打开，提示「Apple 无法验证它是否含有恶意软件」时，点「完成」；
   2. 打开「系统设置 → 隐私与安全性」，往下找到 Mahjong Copilot，点「仍要打开」；
   3. 再次打开，在弹窗里点「仍要打开」。
3. 按提示允许「屏幕录制」：app 只读取雀魂窗口的画面，不操作游戏、不上传任何数据。
4. 第一次启动会下载认牌模型和决策模型（共约 390MB），之后完全离线。

**升级**：直接用新的 DMG 覆盖安装，不需要重新授权屏幕录制。如果某个版本换了签名证书，发布说明里会特别提醒需要重新授权。
