# core — 状态与决策核心

Rust crate，被 [app](../app/) 直接调用。和界面、平台无关，方便单元测试。

- 牌局状态引擎：把 [perception](../perception/) 输出的逐帧观测转成 mjai 格式的事件流，并做一致性校验
- 规则层：向听数（查表）、有效进张、役和番符、和牌概率、防守危险度、推退判断。向听、和牌判定、番符和点数直接调用 [third_party/libriichi](../third_party/libriichi/)；`analysis` 模块在它之上做有效进张和打牌排序
- 目标牌型搜索：枚举可达的和牌组合，按役种路线分组，取期望得点前 3
- 接入 Mortal 决策模型（P2）：用 libriichi 生成输入编码，ONNX 推理，按合法动作掩码过滤
- 规则包：日麻四麻 / 三麻起步，之后扩展国标、四川等
