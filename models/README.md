# models — 模型下载

Rust crate，只在首次启动（或模型缺失）时运行。整个项目只有这里联网。

- 每个模型锁定地址（含修订版）、大小和 SHA-256，见 `src/lib.rs`
- 先下载到 `<文件名>.part`，中断后从断点续传；服务器不支持续传时从头再下
- 大小和哈希都对了才改成正式文件名，所以正式文件一定是完整、校验过的；之后启动只核对大小
- 进度通过回调报告，app 转成 `model-progress` 事件给引导界面（#17）

测试用本机的临时 HTTP 服务器，不联网。下载真实模型（345MB）的测试默认跳过：

```bash
cargo test -p mahjong-models --release -- --ignored
```
