# 麻将 Copilot

运行在 macOS 上的离线麻将出牌助手。它实时读取屏幕上的牌局，用牌图直接标出该打哪张、要不要吃碰杠、以及最值得追的 3 种胡牌牌型。

- 只读屏幕像素：不读内存、不抓包、不注入，也不操作游戏
- 完全离线：识别和决策都在本机完成
- 开箱即用：装好、授权屏幕录制、选中游戏窗口即可
- 短期适配日本麻将（雀魂、雀姬），长期适配任意三人 / 四人麻将游戏（网页版、Steam 单机版）

## 路线图

| 阶段 | 内容 |
|---|---|
| P0 原型 | 雀魂网页版四麻：认出手牌，向听 / 进张计算，侧栏 UI 标出打哪张 |
| P1 MVP | 牌河 / 副露 / 宝牌识别，状态引擎，鸣牌和立直建议，基础防守，目标牌型，叠加模式，首次启动引导 |
| P2 | 策略网络，雀姬，三麻，Steam 客户端，皮肤自适应 |
| P3 | 国标 / 四川 / 广东 / 台湾等规则包，通用版面模型 |

## 使用须知

雀魂等在线游戏的用户协议一般禁止在对局中使用辅助工具，在段位场使用可能导致封号，对真人对手也不公平。本项目定位为学习和练习工具：AI 对战、友人房、牌谱复盘。
