# 麻将 Copilot

离线麻将出牌助手，先支持 macOS，之后支持 Windows。它实时读取屏幕上的牌局，用牌图直接标出该打哪张、要不要吃碰杠、以及最值得追的 3 种胡牌牌型。

- 只读屏幕像素：不读内存、不抓包、不注入，也不操作游戏
- 完全离线：识别和决策都在本机完成
- 开箱即用：装好后在系统设置里确认打开一次，再授权屏幕录制、选中游戏窗口即可
- 短期适配日本麻将（雀魂、雀姬），长期适配任意三人 / 四人麻将游戏（网页版、Steam 单机版）

## 安装（macOS）

1. 下载 DMG，打开后把 Mahjong Copilot 拖进「应用程序」。
2. 第一次打开（只需一次）。app 用我们自己的证书签名，没有经过 Apple 公证，所以 macOS 会拦一次：
   1. 在「应用程序」里双击打开，提示「Apple 无法验证它是否含有恶意软件」时，点「完成」；
   2. 打开「系统设置 → 隐私与安全性」，往下找到 Mahjong Copilot，点「仍要打开」；
   3. 再次打开，在弹窗里点「仍要打开」。
3. 按提示允许「屏幕录制」：app 只读取雀魂窗口的画面，不操作游戏、不上传任何数据。
4. 第一次启动会下载认牌模型和决策模型（共约 390MB），之后完全离线。

以后升级到新版本，直接用新的 DMG 覆盖安装即可，不需要重新授权屏幕录制。

## 技术栈

Tauri 2 + Rust + React / TypeScript，模型用 ONNX Runtime 推理。选型理由见设计方案第七节。

## 使用须知

雀魂等在线游戏的用户协议一般禁止在对局中使用辅助工具，在段位场使用可能导致封号，对真人对手也不公平。本项目定位为学习和练习工具：AI 对战、友人房、牌谱复盘。
