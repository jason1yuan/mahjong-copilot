# profiles — 游戏适配包

每款游戏一个子目录，接入新游戏只加适配包，不改核心代码。适配包只是一个 JSON：只有数字和文字，不含任何游戏截图或素材（游戏美术不能随 app 分发）。包含：

- 窗口匹配规则：应用名、窗口标题、浏览器标签页标题
- 版面比例：以手牌为锚点（#3）。手牌按牌面检测找到；游戏区域按牌间距和手牌位置推出；其他区域（四家牌河、副露、宝牌指示、按钮、分数）用相对游戏区域的比例坐标
- 牌面颜色阈值：找牌面用
- 动作按钮文字：吃 / 碰 / 杠 / 荣和 / 自摸 / 立直 / 跳过（含日文、英文写法）

牌面不用预先准备：运行时由认牌模型认出并缓存成模板（见 `perception`）。

第一个适配包：[`majsoul-web`](majsoul-web/)（雀魂网页版）。
