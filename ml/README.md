# ml — 模型训练

Python + PyTorch，导出为 ONNX，在 [perception](../perception/) 里用 ONNX Runtime 推理。数据和权重不进 git（见根目录 `.gitignore`）。

- 找牌检测器：输出牌框和朝向（0 / 90 / 180 / 270）
- 认牌分类器：34 种牌 + 赤五 + 牌背，长期加花牌；用特征向量 + 原型匹配，新皮肤只需少量样本
- 数字和按钮识别：认局数、本场数、余牌数、分数，给吃 / 碰 / 杠等按钮分类
- 通用版面检测（P3）：没有适配包的游戏也能找出手牌和牌河
- 决策模型（P2）：用 Mortal（haor/Mortal-S42 权重），不自己训练。这里只做 ONNX 导出，以及和原 PyTorch 模型的输出对照测试

训练数据两条来源：

1. 合成数据：多套牌面素材，叠加透视、模糊、压缩、光照变化
2. 牌谱回放自动标注：在游戏里回放已知牌谱并录屏，牌谱本身就是标准答案
