# 创建自签名代码签名证书（#19）

app 不加入 Apple Developer Program，用一张自签名证书签名（见 [design.md](design.md) 第五节）。这张证书要一直用下去：macOS 按签名认出同一个 app，换了证书，所有用户都要重新授权屏幕录制。所以创建一次、备份好，以后每个版本都用它签。

整个过程在打包用的那台 Mac 上做一次，大约 5 分钟。证书、私钥和导出密码都只由你自己操作和保管，不要发给任何人，也不要放进仓库。

## 1. 打开「钥匙串访问」

用 Spotlight（⌘ 空格）搜索「钥匙串访问」（Keychain Access）并打开。较新的 macOS 把它从「实用工具」文件夹里移走了，搜索最方便。

## 2. 创建证书

1. 菜单栏选「钥匙串访问 → 证书助理 → 创建证书…」。
2. 填写：
   - **名称**：`Mahjong Copilot Self-Signed`。打包设置会用这个名字找证书，请照抄，或者告诉我你用的名字。
   - **身份类型**：自签名根证书
   - **证书类型**：代码签名
   - 勾选 **「让我覆盖默认值」**：默认有效期只有一年，到期就得换证书。
3. 点「继续」，下一页把 **有效期（天）** 改成 `3650`（十年），其他保持默认，点「继续」。
4. 后面几页（证书信息、密钥对信息、密钥用法扩展、扩展密钥用法扩展等）保持默认，一路点「继续」。默认值是 RSA 2048 位，用途包括「签名」和「代码签名」。
5. **钥匙串**选「登录」（login），点「创建」，然后点「完成」。

## 3. 设为信任，用于代码签名

自签名证书默认不被信任，`codesign` 可能认为它无效。

1. 在「钥匙串访问」左侧选「登录」，上方选「我的证书」，找到 `Mahjong Copilot Self-Signed`。
2. 双击打开，展开「信任」。
3. 把 **「代码签名」** 改成 **「始终信任」**。关闭窗口时输入你的 Mac 登录密码确认。

## 4. 检查

在「终端」里运行：

```bash
security find-identity -v -p codesigning
```

输出里应当有一行包含 `"Mahjong Copilot Self-Signed"`，前面是一串 40 位的十六进制指纹。看到它就说明证书和私钥都在、可以用来签名。

## 5. 导出备份（.p12）

1. 在「我的证书」里右键 `Mahjong Copilot Self-Signed` → 「导出…」。要从「我的证书」导出，这样私钥会一起导出；只导出证书本身没用。
2. 文件格式选「个人信息交换（.p12）」，文件名例如 `MahjongCopilot-signing.p12`。
3. 设置一个**导出密码**，并把密码存进你的密码管理器。没有这个密码，备份就打不开。
4. 把 .p12 文件放在安全的地方，例如加密的 U 盘、私人网盘里加密的文件夹。不要放进项目文件夹：`*.p12` 绝不能进 git。

换电脑或重装系统时，双击这个 .p12，输入导出密码，就能把证书和私钥导回「登录」钥匙串，然后重做第 3、4 步。

## 6. 第一次签名时

打包时 `codesign` 第一次用这张证书，系统会弹窗问是否允许它使用钥匙串里的私钥。输入 Mac 登录密码，点 **「始终允许」**，以后就不会再问。

## 7. 证书到期前

十年有效期快到时，要提前创建新证书并发布一个用新证书签名的版本。用户装了以后需要重新授权一次屏幕录制，在发布说明里提醒。

## 建好以后

把证书名告诉我（照抄上面的话就是 `Mahjong Copilot Self-Signed`），我来把它写进打包设置，让签名成为构建的最后一步，并用 `codesign --verify --deep --strict` 检查。
